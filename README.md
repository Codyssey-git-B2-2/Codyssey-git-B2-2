# Codyssey-git-B2-2

Codyssey "친구 3~5명과 함께 프로그램 만드는 법 연습하기" 미션을 위한 팀 협업 저장소입니다.
4인 팀이 GitHub Flow, Issue/PR 연동, 코드 리뷰, 충돌 해결, Git 트러블슈팅을 직접 실습하고 기록합니다.

## 구성
- `src/utils.py`: 팀원별 유틸 함수 모음 (`python src/utils.py`로 간단 검증)
- `docs/CONTRIBUTING.md`: 브랜치·커밋·PR·리뷰·충돌 대응 규칙
- `docs/conflict-resolution.md`: 충돌 해결 기록
- `docs/troubleshooting-log.md`: amend / reset --soft / revert / stash 실습 기록
- `SUBMISSION.md`: 팀원별 Issue/PR·리뷰 증빙 인덱스

## 작업 방식
- `main`은 보호 브랜치이며, 모든 변경은 `feature/*` 브랜치 → PR → 1명 이상 승인 후 병합합니다.
- 자세한 규칙은 [CONTRIBUTING](docs/CONTRIBUTING.md)을 참고하세요.
